# ATS Rules & Best Practices

## Resume Formatting

### Supported Formats
- PDF (preferred)
- DOCX
- Plain text

### Critical Rules
1. **Section Order**: Contact → Summary → Experience → Education → Skills
2. **Keywords**: Match job description keywords (case-insensitive)
3. **Dates**: Use MM/YYYY or YYYY format consistently
4. **Symbols**: Avoid fancy Unicode; stick to ASCII

## Keyword Extraction

- Extract from job descriptions
- Weight by frequency and position
- Match against resume sections

## Validation Checks

- Valid date ranges (start ≤ end)
- Contact info present (email/phone)
- At least one experience entry
- No suspicious gaps (>2 years)

## Grounding Rules

- Skills must be mentioned in experience
- Education dates must be realistic
- Current role cannot predate last education
